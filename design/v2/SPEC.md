## 1. 产品是什么（一句话）

一个本地优先的待办 + 日历桌面应用。用户看到的只有**「一件事」**——
没有任务/日程之分。区别只在**时间说到多细**。

## 2. 四个词，五种形状（ADR 0004 §2 · 唯一的可变结构）

用户只需要记四个词；「这周」「下个月」是「一段时间」的预设。

| 用户说的 | 形状 | 行上显示 | 会过期 | 日历上 |
|---|---|---|---|---|
| 「不限」 | 无日期 | 清单名 | 否 | 不出现 |
| 「某天」 | 一天 | 「周五」/「今天」 | 是（次日 0 点） | 当天一格 |
| （某天细分）| 半天 | 「周五下午」 | 是（半天末端） | 当天一格 + 时段标 |
| 「几点」 | 一个时刻 | 「周五 14:00」 | 是（时刻） | 时间轴块 |
| 「一段时间」 | 有起止的区间 | 「这周」/「下个月」/「12/3 – 12/5」 | **否** | **一条横跨它所覆盖那几天的连续横带** |

**关键：「一段时间」在日历上是一条横带，不是每天复制一份。**
同一件事在七个格子里各出现一次，读起来就是七件事。横带是一个连续形状，
眼睛读到的是「这件事占了这一段」。

**排序：粗窗口在前**——一段时间 → 某天 → 半天 → 几点 → 不限。

## 3. 紧急（ADR 0004 §4）

- 用户**可以**标紧急，包括没日期的事。
- 用户**不能**压低时间：明天到期不能说不急。
- 时间侧读数五级：`none`(>14天) / `far`(14–3天) / `soon`(3天–24h) / `near`(24h内) / `urgent`(已过期)
- **只有 `urgent`（已过期）进 Q1**；`near` 不进。信号放行上（「明天到期」+ `--warning-ink`），不靠移动卡片。

## 4. 完成之后

- **留在四象限板**（折叠进「已完成」）。
- **离开日历**。热力图照旧计数（问的是「这天忙不忙」）。

## 5. 视觉规范（不许自创）

- **只用 `design/v2/shared.css` 里的令牌**。不要写 `#3b82f6` 这种字面量。
- 三套皮肤 × 两套主题 = 六个组合，**每个都必须看**（用右上角的演示条切换）。
- 文字 ≥ 4.5:1，UI 边界/状态 ≥ 3:1。
- 图标：**只用内联 SVG，24×24 网格，`stroke="currentColor"`，`fill="none"`，`stroke-width` 随尺寸**
  （14px→1.9 / 16px→1.8 / 18px→1.7）。不要手绘奇怪路径，用 Lucide 的几何。
- 禁止：渐变装饰、玻璃拟态、发光、emoji 当图标、`backdrop-filter` 模糊蒙层。
- 字号只用 `--text-*` 阶梯。圆角只用 `--radius-*`。间距只用 `--sp-*`。

## 6. 文件约定

- 目录：`design/v2/`
- 共享：`shared.css`（令牌 + 基础构件）、`demo.css`（演示条）、`base.js`（皮肤切换）
- 每个片段是一张**独立的 HTML**，`<head>` 里：
  ```html
  <link rel="stylesheet" href="shared.css">
  <link rel="stylesheet" href="demo.css">
  <script src="base.js" defer></script>
  ```
- `<body data-skin="refined" data-theme="light">`；`base.js` 会自动加右上角的皮肤/主题切换条。
- 每张片段最后加一个 `<script>` 做该片段自己的交互。

### 页面骨架（照抄，保证六张拼起来像同一个产品）

```html
<div class="app">
  <nav class="rail" aria-label="主导航"> … </nav>
  <aside class="sidebar"> … </aside>      <!-- 某些视图不需要侧栏，用 .app--wide -->
  <div class="main">
    <header class="topbar"> … </header>
    <div class="content"> … 本片段的正题 … </div>
  </div>
</div>
```

### 交互的最低要求

每个片段至少要有**一种真的能点的东西**：切换、展开、勾选、打开弹层。
纯静态截图不算完成。演示条不占额。

## 8. 必须消灭的概念矛盾（审计里点名的，设计稿不许再犯）

- 不许出现「任务/日程」的选择、徽标、或第二套编辑器。

- 「已过期」的信号：`time` 用 `--danger-ink`，`week`/`month` 用 `--warning-ink`（计划窗口不是承诺）。
- 完成的事不出现在日历上，但出现在板的「已完成」里。
